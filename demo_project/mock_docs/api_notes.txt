# ProjectX API Documentation

## Authentication
All requests require a Bearer token in the Authorization header:

    Authorization: Bearer <your-token>

## Endpoints

### GET /api/v1/tasks
Returns a paginated list of tasks.

Query parameters:
  page   (int) — page number, default 1
  limit  (int) — items per page, default 20
  status (str) — filter: open | in_progress | done

### POST /api/v1/tasks
Create a new task.

    {
      "title":       "string",
      "description": "string",
      "assignee":    "string",
      "due_date":    "YYYY-MM-DD"
    }

### PUT /api/v1/tasks/{id}
Update an existing task (partial updates supported).

### DELETE /api/v1/tasks/{id}
Delete a task. Requires admin role.

## Rate Limits
  Standard plan:    100 req/min
  Enterprise plan: 1000 req/min

## Error Codes
  400 — bad request       401 — unauthorized
  403 — forbidden         404 — not found
  429 — rate limit exceeded
