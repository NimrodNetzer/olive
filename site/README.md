# Landing site

Static landing page for Olive (`/`) and the companion study [mcp-manifest-gap](https://github.com/NimrodNetzer/mcp-manifest-gap) (`/research`).

Plain HTML/CSS/JS, no build step. Deployed on Vercel with **Root Directory = `site`**.

Local preview: `python -m http.server -d site` then open http://127.0.0.1:8000
